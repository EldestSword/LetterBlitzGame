How scoring works

Letter Blitz rules

  1. Blank, wrong-letter or Redcapped answers score 0.
  2. If multiple players give the same accepted answer in one category, every duplicate scores 0.
  3. If one player repeats the same accepted answer across categories in the same round, every repeat scores 0.
  4. A unique valid answer scores 1 point.
  5. A unique valid alliterative answer scores 2 points.
  6. Friendly letters mode skips Q, U, V, X, Y and Z.
