# Roadmap

## Current product shape — v1.0

Letter Blitz now has a dedicated **Control** screen and a separate **Live** presentation screen.

The immediate design principle is:

> Control should make the host faster. Live should make the game clearer.

## Near-term

### 1. Host speed refinements

Potential additions:

- direct keyboard shortcut for Redcap
- optional auto-focus when moving to a category
- one-click jump to the next category containing blanks
- undo last finalised round

### 2. Presentation polish

Potential additions:

- optional sound cues
- alternate Live themes
- richer winner/position-change animation after a finalised round
- optional manual reveal button for games where the timer is not used

### 3. Category management

Potential additions:

- custom category packs
- office-friendly packs
- seasonal packs
- import/export for category lists

## Mid-term

- named session save/load
- edit a finalised round and recalculate totals safely
- CSV export
- printable round recap
- close-match duplicate warnings without replacing host judgement

## Not planned unless explicitly requested

- backend
- authentication
- room codes
- websockets
- framework migration
- AI deciding whether answers are valid
